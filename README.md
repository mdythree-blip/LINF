# LINF Hook 插件项目说明

本插件专为目标 `base.apk` 设计，旨在通过 LSPosed 或免 Root 框架（如 LSPatch）注入，实现广告去除、自动化管理及 UI 自定义功能。

## 功能列表
1. **广告过滤**：
   - 移除开屏广告（通过 Hook `FirstActivity` 的广告回调）。
   - 移除列表及下载弹窗广告（通过 Hook `HomePageItem1Adapter` 及 `DownloadTipsBean`）。
2. **回帖后缀**：
   - 自动在回帖内容后添加“换两行 + 粗体下划线 + LINF修改”的自定义后缀。
3. **家族自动化**：
   - 在家族申请列表、帖子审核列表右上角动态添加“一键同意/审核”按钮。
4. **开屏自定义**：
   - 支持自定义开屏图片及展示时长。
5. **设置弹窗**：
   - 点击“关于我们”或“我的”界面设置图标，弹出功能控制面板。

## 目录结构
- `MainHook.java`: 插件主入口，包含所有 Hook 逻辑。
- `ConfigManager.java`: 配置管理，处理开关状态的持久化。
- `SettingsUI.java`: 动态构建功能设置弹窗的 UI。

## 注入建议
- **LSPosed**: 勾选目标应用并重启。
- **免 Root**: 使用 LSPatch 模式注入，由于软件有签名校验和防护，建议配合核心破解或使用签名模拟插件。
